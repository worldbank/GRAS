# 05. Formal Pseudocode

## Canonical sources

The executable reference behavior is specified in the indicator-level files under
[`docs/pseudocode/`](../pseudocode/). Each file defines the inputs, output record,
detection flow, edge-case behavior, quality checks, and evidence contract for one
indicator family.

The Python implementation and the pseudocode are reviewed together. A behavior
change is complete only when its pseudocode, implementation, and tests agree.
